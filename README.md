# Kalao

[![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/M5S22AP7IF)

**Kalao** (pronounced *ka-la-oh*) is a free, open-source karaoke and lyrics-learning app built with Flutter and Rust. Everything runs on your device: no accounts, no paywall, no tracking. Android comes first; desktop and web follow.

- Design docs: [android/docs/](android/docs/README.md)
- Brand and colour scheme: [android/docs/BRANDING.md](android/docs/BRANDING.md) (sources in [kalaoapp/branding](https://github.com/kalaoapp/branding))
- Extension authoring guide: [android/docs/EXTENSIONS.md](android/docs/EXTENSIONS.md)
- Downloads: [GitHub Releases](https://github.com/kalaoapp/Kalao/releases) (the only distribution channel)

If you'd like to support this project, you can [donate on Ko-fi](https://ko-fi.com/brinsley).
